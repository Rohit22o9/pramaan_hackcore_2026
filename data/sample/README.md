# Sample Data

This directory contains sample and reference datasets used during the development,
testing, and validation of PRAMAAN.

## Purpose

The sample data will help in:

- Testing AI agent inputs and outputs
- Validating agricultural workflows
- Testing data processing and algorithms
- Developing and evaluating future models

## Planned Data

The directory may contain sample data related to:

- Crop information
- Farmer field observations
- Weather records
- Agricultural applications
- Crop health observations
- Product/application records

## Data Privacy

No real farmer personal information or sensitive production data should be
stored in this directory.

Only synthetic, anonymized, or publicly permitted sample data should be used.

## Current Status

The sample data structure is currently prepared for future development.
Datasets will be added as the corresponding AI agents and analytical modules
are implemented.
