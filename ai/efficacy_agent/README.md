# Efficacy Analytics Agent

The Efficacy Analytics Agent is responsible for analyzing field-level data to evaluate the performance of biological agricultural products across different crops, regions, seasons, and field conditions.

It combines validated field observations with product application information, weather conditions, crop information, and historical outcomes to generate evidence-based efficacy insights.

## Purpose

The Efficacy Analytics Agent helps PRAMAAN answer questions such as:

- How effective was a biological product on a particular crop?
- How did product performance vary across regions?
- How did weather conditions affect product performance?
- How did the product perform across different seasons?
- What outcomes were observed after product application?
- Which conditions were associated with better or poorer outcomes?
- What evidence can support recommendations for future applications?

## Input

The agent can receive structured information from multiple PRAMAAN components.

Typical inputs include:

- Crop information
- Biological product information
- Product application details
- Application date
- Field location
- Weather conditions
- Crop observations
- Vision-based observations
- Disease or pest observations
- Harvest outcomes
- Yield information
- Historical field records
- Seasonal information

Crop: Tomato
Product: Biological Product A
Region: Pune
Season: Kharif
